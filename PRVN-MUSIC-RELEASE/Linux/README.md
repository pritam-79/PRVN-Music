# PRVN Music — Linux Distribution Status

## Current Status: Development / Architecture Ready

### Linux Requirements
- **Host System**: Linux x86_64 or aarch64 with glibc 2.31+.
- **Dependencies**: FFmpeg 6.0+ libraries (`libavcodec`, `libavformat`, `libswresample`), ALSA / PulseAudio / PipeWire.
- **Packaging Format**: AppImage, Flatpak, or native `.deb` / `.rpm` packages.
