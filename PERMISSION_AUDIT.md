# PRVN Music v0.15 — Comprehensive Permission Audit

## Overview
This audit inspects every permission requested in `androidApp/src/main/AndroidManifest.xml`, explaining its technical purpose, danger level, runtime request strategy, and Google Play Protect risk classification.

## 2. Risk Mitigation & Justification

### `REQUEST_INSTALL_PACKAGES`
- **Justification:** Required for native self-updating functionality without redirecting users to external browser URLs.
- **Protection:** Handled via runtime check `context.packageManager.canRequestPackageInstalls()`. If disabled, the app directs users to `Settings.ACTION_MANAGE_UNKNOWN_APP_SOURCES`.
- **Integrity Guard:** The in-app updater never passes an unverified APK to the installer. Every APK is verified for package name (`com.prvn.music`), version code continuity, and matching cryptographic certificate.

### `RECORD_AUDIO`
- **Justification:** Used solely for local audio visualizer FFT processing and optional song recognition. Audio is never transmitted or recorded to disk.
- **Protection:** Guarded by runtime permission dialog with clear rationale.

### `CAMERA`
- **Justification:** Used exclusively for scanning the QR code generated by the PRVN Music desktop app for login syncing.
- **Protection:** Camera preview is only active on the Login Sync screen and immediately closes upon barcode scan.
